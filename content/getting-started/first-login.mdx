After installation, open Kaya in a browser and sign in with the configured bootstrap account.

<Callout type="info" title="Recommended first checks">
Change default credentials, verify the public URL, check storage paths and confirm that background services are healthy.
</Callout>

## Initial setup checklist

- Create or confirm the first admin user.
- Add editor or viewer accounts for the operators who need access.
- Review system settings before adding infrastructure records.
- Confirm that audit logging is enabled if your deployment requires traceability.
