Backups should include the database, uploaded files, configuration and any bind-mounted storage used by Kaya.

## What to back up

| Area | Why it matters |
| --- | --- |
| Database | Users, settings, assets, runbooks and operational records |
| Uploads | Screenshots, attachments and supporting files |
| Compose files | Deployment configuration and service wiring |
| Environment files | Hostnames, feature flags and secret references |

<Callout type="danger" title="Secrets">
Store secrets in a secure backup system. Do not publish `.env` files into public repositories.
</Callout>

Restore instructions need the final database engine and volume layout.
