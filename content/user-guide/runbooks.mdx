# Runbook Manager

Open **Documentation > Runbook Manager**. Spaces organise pages for systems, teams or procedures. Pages support a title, tags and Markdown-like content, and may be nested beneath another page.

Viewer can browse, search and filter pages by text, space and tags and switch between tile and table views. Editor and Admin can create spaces, add pages, edit content and delete pages. Kaya saves page history before an update, although the current interface does not provide a complete one-click history restore workflow.

The renderer is Kaya's own limited Markdown-like implementation rather than a full CommonMark engine. Preview complex formatting and avoid relying on unsupported extensions.

<Callout type="danger" title="Page deletion is permanent in the interface">
Confirm the page and its operational value before using the Danger Zone. Restore requires an application backup or direct recovery work.
</Callout>
