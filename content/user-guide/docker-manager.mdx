# VM/Docker Manager

Open **Infrastructure > VM/Docker Manager**. Kaya models a compute host and its discovered workloads, inventory, metrics and events.

Editors and Admins can add a Proxmox host with API connection details or a Docker-agent host. Proxmox token secrets are encrypted at rest. A Docker-agent token is displayed when the host is created; the database stores its hash, so record the token securely for agent configuration. Host poll intervals are bounded by the form.

Open a host to see connection state, last-seen time, resource values, workloads and inventory, then run a sync when the source supports it. Workload pages show status and resource details and allow owner, tags and backup-policy metadata to be maintained. Discovered addresses can link to VLAN/IP Manager records.

<Callout type="info" title="Agent required for Docker">
Adding a Docker host does not install or deploy an agent. The external agent must check in with the generated bearer token and report its capabilities.
</Callout>

Viewer can read. Editor and Admin can manage hosts and workloads. Agent endpoints use bearer tokens rather than browser roles.
