# Domain Manager

Open **Networking > Domain Manager**. Viewers can inspect records; Editors and Admins can create, edit, look up and delete them.

Create a record with the domain name and operational metadata. Kaya's lookup services can collect registrar, expiry, nameserver and DNS information and retain changes in history. A background poller refreshes due records; manual lookup requests an immediate refresh.

External RDAP, WHOIS and DNS responses vary by registry and TLD. A blank or failed field is not proof that the domain lacks that property. Review the stored error and retry before changing the record manually.

<Callout type="danger" title="Deletion removes local history">
Deleting a domain record removes Kaya's record and associated lookup history; it does not alter the registration at the registrar.
</Callout>
