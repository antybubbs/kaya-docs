# IP/WAN Monitor User Guide

## Overview

IP/WAN Monitor provides continuous monitoring of network devices, gateways, public IPs and internet endpoints.

### Features

- Live monitoring
- Latency
- Packet loss
- Jitter
- Availability
- Historical performance
- Incidents

## Dashboard

Each monitor is shown as a live card containing hostname, IP address, latency, availability and a live graph.

Use **Edit Layout** to drag and reorder cards. Your layout is automatically saved and restored.

## Live Modes

- Live (1 second)
- 5 seconds
- 10 seconds
- 60 seconds

Live mode uses a smooth ECG-style scrolling graph.

## Wallboard

Wallboard mode provides a fullscreen monitoring display with configurable columns, responsive cards and live updates.
