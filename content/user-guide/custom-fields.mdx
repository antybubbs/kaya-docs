Admins open **Data Management > Custom Fields** to define fields for IP addresses, hardware assets or licences. Supported types are text, textarea, radio and select. Radio/select fields require valid configured options.

Active fields appear on the related Editor/Admin forms. Disabling a definition hides it from normal entry without automatically deleting stored values. Changing keys, types or options can make existing values inconsistent, so export or back up affected data before structural changes.

Deleting a custom field removes its definition and associated values after confirmation. The underlying value relationship is polymorphic rather than enforced by a database foreign key.
