title: "License Keys"

order: 12
version: "current"
---

Open **Security > License Keys**. The interface uses the spelling **License Keys**, while internal model and import names use `licences`.

Viewer can browse and see masked keys. Editor and Admin can add a product, required key, managed licence type, seat count, favourite state, notes and custom fields. Product keys are encrypted at rest. Revealing a full key requires Editor or Admin and writes an audit event.

<Callout type="warning" title="CSV export exposes plaintext keys">
Admin import/export can decrypt product keys into the exported file. Handle the CSV as a secret, transmit it securely and delete working copies when they are no longer required.
</Callout>

Related: [Import and Export](/docs/user-guide/import-export), [Audit Logs](/docs/administration/audit-and-logging).
