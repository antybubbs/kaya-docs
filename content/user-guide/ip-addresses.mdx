The IP Addresses area is for documenting assigned, reserved and available addresses.

Use it to reduce conflicts and keep network ownership visible.

| Field | Purpose |
| --- | --- |
| Address | The IP address or range |
| Status | Available, reserved or assigned |
| Owner | Service, host or person responsible |
| Notes | Operational context |
