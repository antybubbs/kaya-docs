Admins open **Data Management > Categories**. This page manages lists for Asset Manager category, location and status; VLAN/IP Manager category; and License Keys licence type.

Create, rename, enable, disable or delete values. A disabled or renamed list entry does not rewrite historical text already stored on records. Existing records can therefore continue to display an older value even when it is no longer offered on new forms.

VLAN/IP Manager also exposes its Categories within that module's Site Administration panel. Use one interface consistently and review records before deleting a value.
