Kaya is a self-hosted workspace for documenting, organising, monitoring and operating infrastructure. This guide series starts with Docker basics and leads through first sign-in, hardening, backup and updates.

For any edits to these docs, you can either branch off from this repo or send me an issue on the repo itself.

Here it is: https://github.com/antybubbs/kaya-docs

# Recommended journey

1. Read [What is Kaya?](/docs/getting-started/what-is-kaya).
2. Check the [system requirements](/docs/getting-started/system-requirements).
3. [Install Kaya](/docs/getting-started/installing-kaya).
4. Create the first administrator and [sign in](/docs/getting-started/first-login).
5. Complete the [initial configuration](/docs/getting-started/initial-configuration).
6. Make and test a [backup](/docs/getting-started/backing-up-kaya).
7. Learn the safe [update process](/docs/getting-started/updating-kaya).
