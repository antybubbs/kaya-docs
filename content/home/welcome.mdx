# Welcome to Kaya Docs

This library documents the current Kaya application for operators, administrators and contributors.

- Start with [Welcome to Kaya](/docs/getting-started/welcome-to-kaya) for installation and first configuration.
- Open the [User Guide](/docs/user-guide/dashboard) for active modules and day-to-day workflows.
- Use [Site Administration](/docs/administration/site-administration-overview) for roles and system settings.
- Follow [Integrations](/docs/integrations/pihole) for code-confirmed external services.
- Diagnose failures in [Troubleshooting](/docs/troubleshooting/common-issues).
- Explore the implementation in [Developer Documentation](/docs/developer/overview).

The docs source is maintained in the [Kaya Docs repository](https://github.com/antybubbs/kaya-docs). Product code is maintained separately in the [Kaya repository](https://github.com/antybubbs/kaya).
