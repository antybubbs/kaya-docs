The docs app exposes internal API routes for editor workflows.

| Route | Purpose |
| --- | --- |
| `/api/search` | Returns a local documentation search index |
| `/api/auth/login` | Starts an editor session |
| `/api/auth/logout` | Ends the session |
| `/api/docs` | Lists, creates, updates and deletes MDX files |

These routes are intended for the docs web app. Treat them as internal until an external API contract is designed.
