### About Kaya

Open **System Settings > About Kaya** as an Admin. The page reports application and environment information assembled by Kaya's About and version services. The navigation footer also shows the installed version, development/stable channel and the latest release when GitHub lookup succeeds.

An unknown latest version usually means the release check could not reach or interpret GitHub; it does not mean the installed application is damaged. Use the installed image digest or release tag as the authoritative deployment reference.

The About destination is internal to Kaya. The documentation site does not replace it.
