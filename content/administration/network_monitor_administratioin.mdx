# IP/WAN Monitor Administrator Guide

## Site Administration

Configure:

- Global thresholds
- Wallboard
- Shared URLs
- PIN/passcode
- Session lifetime
- Display defaults

## Diagnostics

Administrator endpoint:

`/networking/ip-wan-monitor/diagnostics`

Shows scheduler state, heartbeat, last execution, last observation, pending monitors and worker uptime.

Capture diagnostics before restarting Kaya when investigating monitoring issues.
