Kaya Docs uses a simple role model:

| Role | Access |
| --- | --- |
| Viewer | Read public documentation |
| Editor | Create and edit documentation pages |
| Admin | Delete pages and manage all documentation settings |

For the main Kaya application, document the exact roles and permissions configured in the product.
