Run Kaya behind a reverse proxy when exposing it over a network.

Common proxy responsibilities include TLS termination, host routing, upload limits, forwarded headers and access logs.

```nginx
proxy_set_header Host $host;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;
```
