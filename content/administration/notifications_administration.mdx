# Notifications Administration

## Overview

Administrators control notification policies, delivery channels and Web
Push configuration.

## Global Settings

Configure:

-   In-App notifications
-   PWA Push
-   Email
-   User customisation

## Web Push

Generate and manage VAPID keys from **Site Administration →
Notifications**.

Kaya encrypts the private VAPID key using the installation
`ENCRYPTION_KEY`.

## Delivery Health

Review:

-   Worker status
-   Queue health
-   Active subscriptions
-   Push failures
-   Retry queues

## Diagnostics

Run:

-   In-app test
-   Push test
-   Delayed background Push test
-   Production event simulation

## Security

Only administrators may manage notification configuration. Private VAPID
keys are never exposed through the UI, APIs or logs.
