## Can I edit docs through Git?

Yes. The source of truth is the `content/` directory, so normal Git workflows work well.

## Can I edit docs through the web app?

Yes. Sign in as an editor or admin and use the editor area.

## Does this version commit changes back to Git?

Not yet. The first version writes to the local content directory. The code is structured so a Git write-back adapter can be added later.
