## The editor cannot save

Check that the container can write to the mounted `content/` directory.

## Search results are stale

The search index is generated from local MDX files. Refresh the page after editing content.

## A page does not appear in the sidebar

Confirm that the file ends in `.mdx`, has valid frontmatter and is inside the `content/` folder.
